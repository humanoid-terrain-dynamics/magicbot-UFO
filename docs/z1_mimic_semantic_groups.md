# Z1 Mimic Semantic Groups

This is the filename-based grouping for the 31 converted Z1 mimic source motions. `chi9_opt` and `getup_a_001` are intentionally excluded by the source dataset.

The source NPZ files were regenerated from the mimic CSVs with the official MagicBot Z1 MJCF:
`humanoidverse/data/robots/magicbot_z1_description/mjcf/MAGICBOTZ1.xml`.

The regeneration uses foot-only grounding (`--ground_mode foot --clearance 0.005`) so the ankle/foot meshes sit just above the floor instead of floating. The training manifest points at 62 selected windows under `humanoidverse/data/z1_mimic_robot_state_npz_selected`, generated by `tools/z1/pick_z1_mimic_clips.py`. The original 31 source motions are kept under `humanoidverse/data/z1_mimic_robot_state_npz`.

## Clip Policy

- `z1_cyclic_locomotion`: continuous or repeatable motions; 2 selected windows per source motion.
- `z1_atomic_skills`: single skills or short combinations; 2 selected windows per source motion.
- `z1_acrobatics_recovery`: flips, inverted motions, and recovery-like clips; 2 selected windows per source motion.
- `z1_pose_low_motion`: poses, squats, stands, and low-motion clips; 2 selected windows per source motion.

## Selection

Run:

```bash
uv run python tools/z1/pick_z1_mimic_clips.py --force
```

The Z1 mimic source motions are in-place, so root xy speed is not useful for scoring. The picker uses sliding windows scored by joint activity, body-position activity, root angular activity, and pose span, then greedily selects 2 low-overlap windows per source motion.

The upstream source NPZ regeneration command is:

```bash
uv run python D:/Desktop_Files/humanoid-terrain-dynamics/magicbot-mimic/scripts/mimic_csv_to_npz.py \
  --csv_dir D:/Desktop_Files/humanoid-terrain-dynamics/magicbot-mimic/source/whole_body_tracking/whole_body_tracking/datasets/raw_csv/mimic \
  --out_dir D:/Desktop_Files/humanoid-terrain-dynamics/magicbot-mimic/source/whole_body_tracking/whole_body_tracking/datasets/mimic \
  --xml D:/Desktop_Files/humanoid-terrain-dynamics/UFO/UFO/humanoidverse/data/robots/magicbot_z1_description/mjcf/MAGICBOTZ1.xml \
  --input_fps 50 --output_fps 50 --ground_mode foot --clearance 0.005
```
